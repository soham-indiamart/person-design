Workflow · data flow · integration

1
Seller file → persona generator (rules + ps04_evidence.json): voice, language, tone, plan, a reason and a confidence per setting. Missing fields → defaults marked low confidence.
2
Seller speaks → Saaras v3: native-script transcript + romanized copy (two parallel calls) + language ID across 23 languages.
3
Behaviour Analyst agent (sarvam-105b-conversations) reads the last 6 turns: seller is calm / aggressive / rushed / confused / interested / suspicious, with intensity + trend. Phrase lexicons are the fallback and the aggression safety net.
4
Persona Director switches between 6 named personas (Friendly Guide, Calm De-escalator, Quick & Direct, Patient Explainer, Enthusiastic Closer, Transparent Reassurer) with hysteresis; back to Friendly Guide after 2 calm turns. Same voice, new delivery. Language mirroring runs alongside. Every switch → switch log.
5
Sarvam LLM writes the reply. Prompt layers: fixed facts + guardrails, then the seller's plan, then the live persona.
6
Bulbul v3 speaks it with speaker, pace, expressiveness and language from the live persona. Sentences are synthesized in parallel.
🧩 Distinctness across 149,363 sellers: 200 distinct combinations of 9 key settings. Two random sellers differ on 3.7 of 9 settings on average. Seller types used to explain the logic: time-pressed 43% · standard 23% · new & receptive 14% · guarded 12% · established/formal 5% · already engaged 2% · do-not-call 1% (no call).
